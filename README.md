МЕНЕДЖЕР ЗАДАЧ

- Простое веб-приложение для управления задачами. Сделано в рамках прохождения практики.

ТРЕБОВАНИЯ К ЗАПУСКУ:

- Установленный PostgreSQL
- Установленный Python
- Установленный Node.js

ЗАПУСК:

1.  - Открываем командную строку
    - Вводим: cd C:\OSPanel\domains\task-manager\backend  (Моя директория проекта)
    - Вводим: npm start

(Если не вывело ошибок то продолжаем:)

2.  - Открываем командную строку (ещё одну, первая должна быть открыта и активна)
    - Вводим: cd C:\OSPanel\domains\task-manager\frontend  (Моя директория проекта)
    - Вводим: npm start

(Должен открыться браузер с менеджером задач)

3.  - Открываем командную строку (ещё одну, первые две должны быть открыты и активны)
    - Вводим: cd C:\OSPanel\domains\task-manager\python  (Моя директория проекта)
    - Вводим: python export_tasks.py

(Экспортирует задачи в CSV-формат)


Команды на случай ЧП:
- python -m pip install psycopg2-binary python-dotenv
